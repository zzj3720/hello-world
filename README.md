# Hello World

A minimal Node.js program that prints `Hello, World!`. No dependencies.

## Requirements

- [Node.js](https://nodejs.org/) 18 or newer

## Run

```sh
git clone https://github.com/zzj3720/hello-world.git
cd hello-world
npm start        # or: node index.js
```

Expected output:

```
Hello, World!
```
